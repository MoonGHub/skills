# Quality Check

Use this only before final reporting. Rate applicable items `상`, `중`, `하`, or `확인 필요` with one short reason; do not repeat the checklist itself in generated docs.

- **Scope and mode**: Initialize, Refresh, or Full Reapply matches the request; Initialize and Full Reapply covered every owned source root, while Refresh followed `REFRESH-01` through `REFRESH-04` without escalating for ordinary structural growth.
- **Routing and semantic depth**: every in-scope candidate was evaluated under `SCOPE-01` and `PLACE-01`; new/deeper Refresh paths and placement transitions are covered, and every narrow high-risk exception has a recorded reason.
- **Source grounding**: current contracts have valid repository-relative anchors; facts, inference, and unknowns are separated.
- **Refresh provenance**: baseline trust, committed/dirty/untracked paths, topology changes, coverage policy, and row advancement satisfy `REFRESH-02` through `REFRESH-04`.
- **Portable continuation**: operation docs support a clean machine; active unfinished work uses handoff and states commit/push limits.
- **Ownership preservation**: manual/unknown docs and user rules were preserved; only verified managed docs were retired.
- **Useful coverage**: all meaningful candidate folders from the detected specialist reference were evaluated; meaningful owners, entrypoints, flows, interfaces/data, commands, and high-risk boundaries are covered without file-level or absent-section noise.
- **Contract ownership**: each confirmed cross-boundary dependency has at most one canonical map and no copied schema/detail.
- **History quality**: current state was updated before the concise daily record; index, evidence, and multi-project ownership follow policy.
- **Refresh context efficiency**: Refresh began with routed context, loaded only candidate-driven references and source, preserved useful modular documents, and avoided unrelated whole-owner or whole-repository reads.
- **Discovery discipline**: `DISCOVERY-01` excluded ignored/output paths, external symlink targets, and unnecessary large/binary/minified content from discovery and anchors.
- **Safety and change scope**: changed-doc sensitive-pattern matches were reviewed without reporting values; the agent-introduced delta contains no private values or unintended source/runtime/generated/vendor changes, and unrelated pre-existing worktree changes remain untouched.

Report generated/updated/retired/preserved paths, remaining `확인 필요`, validation performed, and why application tests were skipped when documentation alone changed. Summarize affected boundary placement decisions and exceptions; do not repeat unchanged inventories.
